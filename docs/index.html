Ranked-choice voting widget: samples

Four live sample elections, each embedded with one <rcv-election> tag. Votes are real and are counted on elections.appfarms.org. Each browser gets one vote per election.

Load the script once per page:

<script src="https://elections.appfarms.org/widget.js" defer></script>

1. Single winner (instant runoff)

  • seats = 1
  • live results

The simplest case: one seat, so the count is an instant runoff. Results show right after you vote.

Embed code 
<rcv-election election-id="rcvwidget-sample-pizza-topping"
  title="Best pizza topping"
  description="Rank as many as you like. Pineapple opinions welcome."
  candidates="Pepperoni|Mushroom|Sausage|Pineapple|Margherita (basil)|Jalapeño">
</rcv-election>

2. Three winners (single transferable vote)

  • seats = 3
  • Droop quota
  • surplus transfers

More than one seat switches the count to STV. When a winner has more votes than they need, the extra votes pass to later choices.

Embed code 
<rcv-election election-id="rcvwidget-sample-book-club-2027"
  title="Book club: three picks for 2027"
  description="The top three books become next year's reading list."
  seats="3"
  candidates="Project Hail Mary|The Remains of the Day|Piranesi|Educated|Klara and the Sun|The Overstory|Station Eleven|A Gentleman in Moscow">
</rcv-election>

3. Sealed results with a deadline

  • closes
  • live-results = false

Results stay hidden until voting closes, so early votes can't sway later ones. Voting ends 31 March 2027.

Embed code 
<rcv-election election-id="rcvwidget-sample-team-offsite"
  title="Spring team offsite location"
  description="Results are revealed when voting closes."
  candidates="Mountain cabin|Beach house|City hotel|Lakeside camp|Stay home, bigger budget for food"
  closes="2027-03-31T23:59:00Z"
  live-results="false">
</rcv-election>

4. Custom styling, fixed order

  • seats = 2
  • shuffle = false
  • JSON candidates
  • CSS variables

Two winners. The candidate list is a JSON array, which helps when names contain a |. Candidates keep the given order, and the host page restyles the widget with --rcv-* variables and ::part(submit).

Embed code 
<style>
  #garden {
    --rcv-accent: #2f7d4f; --rcv-soft: #eef6f0; --rcv-border: #cfe3d6;
    --rcv-radius: 4px; --rcv-font: Georgia, serif;
  }
  #garden::part(submit) { text-transform: uppercase; letter-spacing: .06em; }
</style>
<rcv-election id="garden" election-id="rcvwidget-sample-community-garden"
  title="Community garden: two new beds"
  description="Pick the two plantings for the new raised beds."
  seats="2"
  shuffle="false"
  candidates='["Tomatoes & peppers","Herbs | basil, mint, thyme","Pollinator flowers","Strawberries","Squash & pumpkins"]'>
</rcv-election>
Full attribute reference, animated results and explainers: elections.appfarms.org. A browser can vote once per election. This is a poll, not a secure election.
