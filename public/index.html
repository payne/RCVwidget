Embed a ballot on your site

Works on any website: paste the script once, then add a <rcv-election> tag wherever you want a ballot.

<script src="https://elections.appfarms.org/widget.js" defer></script>

<rcv-election
  election-id="example-com-board-2026"
  title="Board of Directors 2026"
  description="Choose three directors."
  candidates="Alice Chen|Bob Ruiz|Carla Diaz|Dev Patel|Erin Wu"
  seats="3"
  closes="2026-12-31T23:59:00Z">
</rcv-election>

Try it

This is a live ballot. Your vote goes into a real election you can watch below the ballot.

Attributes

AttributeMeaning
election-id requiredUnique, lowercase, 3–80 characters (a–z, 0–9, . _ -). Ids are global, so start yours with your domain, e.g. example-com-…
title requiredShown at the top of the ballot.
candidates requiredSeparated by |, or a JSON array. 2–40 candidates.
seatsNumber of winners (default 1). 1 = instant runoff; more = single transferable vote.
descriptionShort text under the title.
opens, closesISO 8601 date-times, e.g. 2026-12-31T23:59:00Z.
live-resultstrue (default) shows results while voting is open; false hides them until closes.
unlistedtrue keeps the election off the public list on this site.
shufflefalse shows candidates in the order given (default: shuffled per voter).
themeauto (default), light or dark.

Good to know

  • Settings lock on first use. The first page that loads an election-id sets its title, candidates, seats and dates. Any embed of the same id must use identical settings, or it shows an error. To change an election, use a new id.
  • The same election can be embedded on many sites. All ballots go into one count.
  • One vote per browser. The widget remembers that a browser voted using that site's local storage, and the server rejects repeat ballots from the same browser. This is a poll, not a secure election: someone who clears their storage or switches browsers can vote again, within a per-network rate limit.
  • Styling. Set CSS custom properties on the element, such as --rcv-accent, --rcv-bg, --rcv-fg, --rcv-border, --rcv-radius and --rcv-font, or style the parts ::part(card), ::part(submit), ::part(candidate) and ::part(ranked-item).
  • Events. The element fires rcv-voted (with detail.ranking) and rcv-error.
